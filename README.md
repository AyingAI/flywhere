# 飞哪里 FlyWhere

根据票价，决定飞哪里。

飞哪里是一个本地运行的机票探索工具：固定出发和回程日期后，从真实航班结果中比较全国目的地，并通过地图、列表和往返组合帮助你判断“这次去哪里更划算”。

## 你会得到什么

- 按全员往返含税预算比较目的地，而不是只看单程日历低价。
- 地图与列表两种视图，每个目的地汇总航司、时间、价格和可用天气。
- 展开目的地后对比去程与回程组合，两程可以来自不同航司。
- 查询记录保存在浏览器本地，恢复历史结果不会重复请求飞猪。
- 可选使用 OpenAI 兼容 API 或本地 AI CLI 辅助排序。

## 5 分钟开始使用

### 1. 准备环境

- [Node.js 20+](https://nodejs.org/)
- 飞猪查询工具：

```bash
npm i -g @fly-ai/flyai-cli
```

### 2. 获取飞猪 API Key

前往[飞猪 AI 开放平台](https://flyai.open.fliggy.com/)，注册并获取自己的 API Key。

### 3. 启动项目

```bash
git clone <你的仓库地址>
cd flymap
npm start
```

打开 <http://127.0.0.1:4173>，点击右上角“运行设置”，填写飞猪 API Key 并保存。回到首页设置日期，点击“搜索低价目的地”。

> AI 辅助排序不是查询机票的必要条件。没有 AI Key 或本地 AI CLI，也可以完成航班搜索、地图浏览与价格比较。

## 运行设置

### 飞猪数据能力（必需）

飞猪 API Key 用于调用 `flyai` CLI 查询真实航班。设置保存在项目目录的 `.flymap-config.json`，权限为 `0600`，该文件已被 Git 忽略。

### AI 辅助排序（可选）

两种方式任选其一：

- OpenAI 兼容 API：填写服务根地址或带 `/v1` 的地址、API Key 和模型 ID。
- 本地 CLI 授权：自动探测 Codex、Claude Code、Gemini CLI、Pi、Kimi Code 与 OpenCode，并使用已有本地授权。

也可以复制 `.env.example` 为 `.env` 后配置环境变量。网页中的本机设置优先于 `.env`。

## 数据与价格口径

服务端分别查询去程和回程，并保留符合筛选条件的目的地与可配对组合：

```text
全员总价 =（去程票面价 + 回程票面价 + 去程费用 + 回程费用）× 成人数量
```

如果 FlyAI 返回费用字段，优先使用接口费用；否则采用预算兜底：每人每航段机场建设费 50 元、燃油附加费 60 元。页面会标记费用来源为“接口”或“预估”，最终价格和余票以飞猪下单页为准。

相同条件会复用 30 分钟服务端快照。浏览器保存最近 12 条成功查询；调整人数只在本地重算，不再次请求飞猪。已去过城市标记也保存在浏览器本地，只影响排序，不隐藏结果。

天气来自 [Open-Meteo](https://open-meteo.com/)。仅在行程进入可靠预报窗口时展示，无法预报时不显示占位信息。

## 本地数据与网络请求

- `.flymap-config.json`：飞猪与 AI 设置，仅保存在本机。
- 浏览器 `localStorage`：查询记录和“已去过”标记。
- 飞猪 AI 开放平台：航班查询。
- Open-Meteo：目的地天气与地理编码。
- 阿里云 DataV：国内地图边界。
- jsDelivr：由本机服务下载并缓存 ECharts 运行时。
- Gitee：加载项目 Logo（按品牌要求使用外链）。
- Google Fonts：尝试加载界面字体；访问失败时使用本机字体回退。
- 你配置的 AI 服务或本地 CLI：仅在主动点击“AI 帮我选”时使用。

服务默认只监听 `127.0.0.1`。当前没有用户登录与权限系统，不要直接部署到公网。详见 [SECURITY.md](SECURITY.md)。

## 常见问题

### 搜索提示“飞猪数据能力尚未就绪”

确认已经安装 `flyai` CLI，并在“运行设置”中保存有效的飞猪 API Key。重新打开终端后可运行 `flyai --help` 检查安装。

### 模型列表读取失败

这不影响航班查询。检查 OpenAI 兼容接口地址、API Key 和网络；也可以切换到已授权的本地 CLI。

### 相同条件为什么不重复请求？

项目会复用 30 分钟服务端快照，查询记录恢复也不会请求飞猪。这是为了减少等待和上游限流。
